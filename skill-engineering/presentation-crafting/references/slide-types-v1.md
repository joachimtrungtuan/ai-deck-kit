# Slide Types V1

Every v1 template set must support these slide types.

## Foundation

| Type | Use |
| --- | --- |
| `title` | Opening title with core promise or topic. |
| `section-divider` | Major chapter transition. |
| `closing` | Final takeaway, CTA, or discussion prompt. |
| `agenda` | Roadmap or session structure. |

## Text-Led

| Type | Use |
| --- | --- |
| `text-statement` | One bold idea with short support text. |
| `text-list` | 3-5 bullets with clear hierarchy. |
| `two-column-text` | Compare two related ideas. |
| `quote` | Strong quotation or principle. |
| `numbered-framework` | Step-by-step framework. |

## Visual-Led

| Type | Use |
| --- | --- |
| `full-bleed-image` | Image as the primary emotional or contextual carrier. |
| `image-text-split` | Image and explanation with balanced hierarchy. |
| `image-grid` | 2-6 related visuals. |
| `icon-grid` | Concepts represented with one icon family. |
| `diagram` | Process, system, map, or relationship. |

## Data And Evidence

| Type | Use |
| --- | --- |
| `metric-highlight` | One to three important numbers. |
| `chart` | Line, bar, area, scatter, or comparable data visualization. |
| `evidence-stack` | Source-backed evidence blocks. |
| `case-study` | Context, action, result. |

## Product Or Workflow

| Type | Use |
| --- | --- |
| `process-flow` | Linear or branching workflow. |
| `before-after` | Contrast old and new states. |
| `ui-showcase` | Product screenshot or interface walkthrough. |
| `timeline` | Sequenced milestones. |

## Rule

If a needed slide cannot fit these types, use the nearest type plus a documented override. Add a new slide type only when the need is reusable across decks.
