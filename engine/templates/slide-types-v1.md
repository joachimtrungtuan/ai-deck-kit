# Slide Types V1

The v1 catalog mirrors the Presentation Crafting skill baseline. Template sets that declare `slideTypeCatalog: "v1"` must support every type below.

## Foundation

| Type | Required Swiss Modern component |
| --- | --- |
| `title` | `SwissTitleSlide` |
| `section-divider` | `SwissSectionDividerSlide` |
| `closing` | `SwissClosingSlide` |
| `agenda` | `SwissAgendaSlide` |
