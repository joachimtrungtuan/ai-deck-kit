# Swiss Modern Icon Policy

Use Phosphor React icons for this template.

## Defaults

- Family: `@phosphor-icons/react`
- Weight: `regular`
- Size scale: `24`, `32`, `48`
- Stroke feeling: precise, quiet, editorial, not playful

## Rules

- Use icons only for concept labels, process nodes, or compact evidence cues.
- Prefer typography, rules, and grayscale imagery before adding icons.
- Do not mix icon families inside a deck.
- Do not use emoji as icon substitutes.
- Keep icon containers square, sharp-cornered, and aligned to the slide grid.
- Do not use plus signs, crosshair marks, or grid-intersection symbols as decorative icons in this template.
- If static HTML export cannot bundle React icons, use `@phosphor-icons/web` with the same icon names and weight.
