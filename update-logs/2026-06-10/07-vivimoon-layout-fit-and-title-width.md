# 07 — VIVIMOON layout fit and title width

## What changed

- Widened title regions in the `linear-dark` slide layouts that the VIVIMOON deck uses, so long Vietnamese titles wrap less aggressively.
- Updated `LinearProcessFlowSlide` so the business-goal cards stretch to equal height and the connector arrows sit centered between cards.
- Reduced `LinearDataFlowSlide` row density: smaller padding, tighter columns, smaller mono/body text so slide 8 fits inside the frame.
- Shifted the `linear-dark` template palette from indigo/purple-leaning accents to energy-blue shades/tints across accent, spotlight, glow, and code emphasis tokens.

## Why

User requested layout cleanup for the VIVIMOON deck: equal-height business-goal boxes, centered arrows, wider title areas, data-flow items that no longer overflow, and a cleaner energy-blue palette without purple cast.
